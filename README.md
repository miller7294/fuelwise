# FuelWise

Sample Flutter project for CSCI410 Mobile Application, Project 1.

FuelWise will be a one-page trip fuel calculator: choose a type of transport,
enter the distance and fuel price, and get the litres needed, the total cost,
the cost per passenger and the CO2 produced. It uses no database.

This repository currently holds the sample project submitted with the
proposal. The full app will be added for Part 2.

## Run

Requires the Flutter SDK.

```
flutter create .
flutter run
```

`flutter create .` is needed once, to generate the Android / iOS / web folders
that are not stored in this repository yet.
